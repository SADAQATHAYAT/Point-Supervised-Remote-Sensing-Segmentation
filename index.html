Project Overview

Challenge

Pixel-level annotation of satellite imagery requires 8-12 hours per image. For a 2448×2448 image, that's labeling 6 million pixels—impractical for large-scale remote sensing projects.

Solution

Weakly-supervised learning using sparse point annotations. Only label 2% of pixels (120,000 points) instead of all 6 million, reducing annotation time from hours to minutes.

Achievement

76.8% mIoU with just 2% annotated pixels—achieving 95% of fully-supervised performance while reducing annotation workload by 95%.

Dataset: DeepGlobe Land Cover Classification

Specifications

  • 803 high-resolution satellite images
  • Resolution: 2448×2448 pixels per image
  • 6 land cover classes (Urban, Agriculture, Rangeland, Forest, Water, Barren)
  • Training/Validation split: 80/20

Class Distribution

Urban: 15%
Agriculture: 25%
Forest: 22%
Water: 18%

Methodology

1. Partial Cross-Entropy Loss

Traditional cross-entropy requires labels for every pixel. Our Partial Cross-Entropy (PCE) loss computes gradients only on annotated points, allowing training with sparse supervision.

LPCE = -1/N ∑i∈Annotated yi · log(pi)

Where N = number of annotated points, yi = ground truth label, pi = predicted probability

2. Point Sampling Strategies

Random Sampling

Uniform random selection across the entire image. Simple baseline approach.

Stratified Sampling

Proportional representation of each class. Best for imbalanced datasets.

Edge-Aware Sampling

Biases selection toward class boundaries using Sobel edge detection.

3. Network Architecture

Modified U-Net with ResNet34 encoder

# Architecture Summary Encoder: ResNet34 (ImageNet pretrained) Decoder: 4 upsampling blocks + skip connections Output: 6-channel softmax (land cover classes) Input: 512×512 RGB patches Parameters: ~24.4M

Implementation

Partial Cross-Entropy Loss Function

import torch import torch.nn as nn import torch.nn.functional as F class PartialCrossEntropyLoss(nn.Module): """ Partial Cross-Entropy Loss for point supervision. Only computes loss on annotated pixels, ignoring unlabeled regions. """ def __init__(self, ignore_index=-100): super().__init__() self.ignore_index = ignore_index def forward(self, predictions, targets, mask): # predictions: [B, C, H, W] - model output logits # targets: [B, H, W] - ground truth labels # mask: [B, H, W] - 1 for annotated, 0 for unlabeled # Apply log softmax to get log probabilities log_probs = F.log_softmax(predictions, dim=1) # Convert targets to one-hot encoding targets_one_hot = F.one_hot(targets, num_classes=predictions.shape[1]) targets_one_hot = targets_one_hot.permute(0, 3, 1, 2).float() # Compute loss only for annotated pixels loss = -(targets_one_hot * log_probs).sum(dim=1) loss = (loss * mask).sum() / (mask.sum() + 1e-8) return loss

Point Sampling Implementation

import numpy as np from scipy.ndimage import sobel def sample_points(mask, n_points, strategy='random'): """ Sample point annotations from ground truth segmentation mask. Args: mask: Ground truth segmentation [H, W] n_points: Number of points to sample strategy: 'random', 'stratified', or 'edge_aware' Returns: y_coords, x_coords: Arrays of sampled point coordinates """ H, W = mask.shape if strategy == 'random': # Uniform random sampling across entire image indices = np.random.choice(H * W, n_points, replace=False) y_coords = indices // W x_coords = indices % W elif strategy == 'stratified': # Sample proportionally from each class points_per_class = n_points // len(np.unique(mask)) y_coords, x_coords = [], [] for class_id in np.unique(mask): class_mask = (mask == class_id) class_indices = np.where(class_mask.ravel())[0] if len(class_indices) >= points_per_class: sampled = np.random.choice(class_indices, points_per_class, replace=False) else: sampled = class_indices y_coords.extend(sampled // W) x_coords.extend(sampled % W) elif strategy == 'edge_aware': # Compute edge magnitude using Sobel operator edges = np.sqrt(sobel(mask, axis=0)**2 + sobel(mask, axis=1)**2) # Sample with probability proportional to edge strength probs = edges.ravel() + 0.1 # Add small constant for stability probs /= probs.sum() indices = np.random.choice(H * W, n_points, p=probs, replace=False) y_coords = indices // W x_coords = indices % W return np.array(y_coords), np.array(x_coords)

Experimental Results

Experiment 1: Effect of Point Density

Hypothesis: Increasing point annotation density will improve segmentation performance, but with diminishing returns beyond a certain threshold.

Annotation Density mIoU (%) Pixel Accuracy (%) F1 Score Training Time
0.1% 48.3 62.7 0.521 28 min
0.5% 63.2 74.8 0.658 32 min
1.0% 71.5 81.3 0.742 36 min
2.0% ⭐ 76.8 85.9 0.798 42 min
5.0% 78.4 87.2 0.812 55 min
10.0% 79.7 88.1 0.823 68 min
Fully Supervised (100%) 81.2 89.5 0.836 78 min

Key Findings

  • Optimal Density: 2% annotation achieves 95% of fully-supervised performance
  • Cost Savings: 98% reduction in annotation effort (from 100% to 2%)
  • Time Efficiency: Training 46% faster (42 min vs 78 min)
  • Diminishing Returns: Beyond 2%, each 1% increase yields only +0.5-1.0% mIoU gain
